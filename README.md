## Core Bash Scripting Challenges
Below are some of the script challenges with comments explaining what the code does.

### Challenge 1: Basic Arithmetic Calculator.
A Script takes two numbers from the user and performs basic arithmetic operations. (Addition, Subtraction, Division, Multiplication)
Requirements

. Prompt the user for two numbers

.Perform all four operations

.Display the results

.Handle division by zero


Example output:

Enter first number: 10 Enter second number: 5

Results: 10 + 5 = 15 10 - 5 = 5 10 × 5 = 50 10 ÷ 5 = 2
